# 讨论脑图实例

独立、零 npm 依赖、只读的 Xmind 风格 HTML 脑图；不是原生 `.xmind`。内容来自本次用户口述，通过对话维护 `data.json`，不含录音、转写、图片或旧主题内容。

## 启动与停止

在用户可见终端前台运行（Node.js 22+，建议当前受支持的 LTS；无 npm 包、鉴权、其他技能或外部网络依赖）：

```text
node "<instance-directory>/server.mjs"
```

服务输出实际 URL，默认端口在 `instance.json`。可追加 `--port 8932` 临时换端口。访问 `/health` 核对 `instanceId`，避免看见别的实例。仅监听本机 `127.0.0.1`，无系统常驻、自启或公网发布。停止：在**本次启动终端 Ctrl+C**。端口占用时换端口，不杀未知进程。创建目录不等于服务已运行；关闭终端后实时服务停止。

stdout 启动给 `running` JSON，正常退出给 `stopped` JSON；诊断日志写 stderr。强杀与系统崩溃不能保证最终 JSON。

## 内容维护

`data.json` 是内容源；不要编辑 `/data.js`（它由服务按有效 JSON 动态生成）。有技能时，通过 inspect/update 脚本以原始文件 SHA-256 防止覆盖并发更新。脱离技能目录后，本实例仍能独立启动与浏览；也可用文本编辑器维护 `data.json`（保留唯一 ID 和 generation，建议同目录原子保存），服务验证后自动同步，无效内容保留上一版本。原子锁/哈希更新工具属于技能，不是启动依赖。标题/节点仅提炼用户说过的内容，保留顺序、关系、范围和语气；不要为填满画布生成观点。

所有节点有稳定 `id`。改名/移动/排序保留 ID，新节点自动分配；重置只清本实例并生成新 generation。无效快照不会替换当前页面。目录监听支持原子保存，SSE 断线重连接收最新完整内容。普通更新保留视角、选中、折叠和聚焦，重置则清当前页面瞬态状态。

## 操作

- 单击选中，双击或 **F** 聚焦分支；圆形按钮折叠/展开，保持节点位置。
- **全图适配 / Shift 1**；**Shift 0 / 百分比** 100%；**+ / −** 缩放；空白拖动平移。
- 触控板模式：双指滚动平移，**Ctrl / ⌘ + 滚轮**按指针缩放（支持常见 Ctrl-wheel 捏合映射）。鼠标模式：滚轮缩放，**Shift + 滚轮**水平平移。右下角选择设备。
- **← / →** 父/子节点，**↑ / ↓** 相邻节点；**Esc** 关闭搜索/帮助或返回全图。
- **⌘ / Ctrl K** 搜索标题和备注（含已折叠节点），Enter 展开祖先并定位。
- **开始演示**按根节点 children 原顺序，一段一镜头，不生成额外内容。空图不进入演示。
- 演示 **空格 / →** 下一段，**←** 上一段，**Esc** 退出；8/15/30 秒自动预览，到尾停止，不是发言计时。全屏可选。
- 演示退出恢复之前视角/折叠/选中/聚焦；SSE 更新保持当前段落 ID 并暂停。删除当前段落回退相邻序位，无段落时退出。
- 窗口改变：全图/聚焦重新适配，手动视图保持中心。全图很大时请用聚焦或搜索进入可读尺度。

## 文件

`index.html` 页面；`styles.css` 样式；`app.js` 布局交互与 SSE 客户端；`server.mjs` 静态资源、健康检查和 SSE；`data-utils.mjs` JSON 校验；`instance.json` 实例身份/端口；`data.json` 内容。
