# Cover Playbook

用于判断排版和创意的经验参考，不是平台官方规格或点击率实验证据。具体内容、用户选择和缩略图可读性优先。

---

## 一、可按内容选择的排版方法

工具演示与个人经验类视频的重心可能不同；先读懂受众与内容承诺，再选择表现手段。

**1. 文字是主体，不是配角**
需要解释价值的内容，通常应让关键文字足够大。真人可帮助观众关联讲述者，但不应挤掉读懂主题所需的文字。

**2. 对比度服务阅读**
背景复杂时可用描边或阴影；深绿底配米白、金色也可以通过对比保持清楚。不必强制粗黑边、霓虹或立体字。

**3. 双行是实用起点**
主题标识、两行主标题和一条简短副标题可以形成清楚层次；分行应让语义自然，不为视觉节奏拆散关键场景。

**4. 配色沿用内容和账号方向**
深底加亮色是可选方案，关键是主题和人物清楚。用户已经认可配色时延续它，避免为增强冲击不断换风格。

**5. 人脸有效但非必需**
经验分享可以使用自然的真人画面，产品演示可以使用真实截图；用户愿意采用 IP 时再用 IP。不要把现成立绘当成默认必加项。

**6. 问题与数字要有内容支撑**
疑问句可以说出观众的目标，例如“面试怎么拿高分？”。数字应来自内容；“3 个方法”可以对应原片的三个并列观点，不能虚构成绩。

**7. 克制不等于含糊**
留白、较少元素和自然真人可以适用于经验分享；主标题仍需说清场景和受众利益。没有实际点击数据时，不把风格偏好说成效果结论。

## 二、多比例交付与安全区

平台名不等于固定比例：同一平台可能有不同上传入口、封面编辑框、信息流和主页裁切。以下是工作室输出规格及排版起点，**不是平台官方强制尺寸**。实际以当前上传页的比例选项与预览为准。

| 比例 | 输出尺寸 | 建议布局与用途 |
|---|---|---|
| 16:9 | 1920×1080 | 宽屏入口；左侧大标题、右侧人物，避免关键内容贴边 |
| 4:3 | 1920×1440 | 较窄横屏入口；压缩左右布局跨度，增加上下空间，不截掉首字和人脸 |
| 1:1 | 1600×1600 | 方形入口；标题上移、人物放下半部，不从横版直接居中裁切 |
| 3:4 | 1080×1440 | 竖向信息流候选；上字下人，副标题及真实素材证据适当重排；这不是方版 |
| 9:16 | 1080×1920 | 全屏竖向入口；关键信息向中上、左侧集中，底部预留界面空间 |

### 默认交付范围

跨平台或未指定比例时提供五种；明确只要某种比例或只做预览时，不强制额外生成。先锁定标题、系列编号、人物帧及配色，再扩展比例，避免每张生成后人物神态和文案都不同。

### 安全区是预留策略，不是保证

- 全部比例先给文字和完整面部预留约 5% 内边距，再根据发布预览修正。
- B 站候选版可先避开底部约 12% 的关键文字，检查时长、播放量等实际覆盖位置。
- 抖音全屏候选版可先避开底部约 25%、右侧约 15% 的关键内容；主页缩略图还可能采用不同裁切。
- 小红书需分别看封面编辑框与信息流预览，不能断言所有入口都使用 3:4，或都有固定底部覆盖范围。
- 用户给了截图时，先确认裁切框而不是整个编辑窗口的长宽；截图测量只是估计。分辨率不足、比例不符、编辑器放大是不同问题，分别排查。

### 不同比例如何生成

1. **优先独立排版**：保持文字、系列号、人物身份和选定表情一致，重排标题、截图证据、人物与 IP 的位置及大小。
2. **禁止硬裁和拉伸**：16:9 铺满 4:3 容易丢左右，竖图转方图容易丢上下。输出前检查完整内容，而不是只看尺寸正确。
3. **补边是降级方案**：保留全部像素但会增加留白、缩小主体。只有作为临时兼容图或用户接受时交付，命名例如 `补边适配_v1_4比3_1920x1440.png`，说明不是重排版。
4. **现有脚本边界**：`compose_cover.py` 仅实现 bilibili、douyin、xiaohongshu 三个预设，分别是 16:9、9:16、3:4；不能传入不存在的 4:3 或 1:1 预设。缺失比例另行排版或使用可用图生图能力，生成后核验尺寸。

### 逐版验收

- 核验像素尺寸与比例；不得靠非等比缩放纠正错误比例。
- 查看完整图和约 300 像素宽的缩略图；标题首尾、系列号、人物面部及 IP 均可辨认且不冲突。
- 制作带比例和尺寸标签的五版总览，交付时说明哪张适合用户当前入口。
- 有发布预览时对照验证；没有时标注「文件比例已核验，平台裁切待上传确认」，不宣称完全兼容所有入口。

> 小红书版可适当使用暖色纸张、留白和高饱和色块，兼顾信息密度与阅读感；具体风格仍以用户已选主视觉为准。

## 三、七种可选创意方向

### 1. 左右对撞（因果型）
左半模糊的"输入"（代码、素材、原始状态），右半清晰高饱和的"输出"，中间巨大箭头。
**适用**：观众好奇"这东西怎么来的"。一眼说清输入→输出，不看标题也懂。

### 2. 悬念否定（反差型）
全屏放成品，压一行大字否定常识：「这张图，我没画」。
**适用**：中文社区，反差感强，评论区会自己吵起来。

### 3. 手稿对比（痛点型）
左边凌乱手绘/打红叉的旧方式，右边精美的新方式。
**适用**：情绪冲击最强，直戳目标人群的真实痛点。

### 4. 全息动态（技术炫技型）
3D 等距全息图 + 光带流动 + 鼠标悬停 tooltip。
**适用**：要表达"可交互、会动"。**必须配真实截图做底**，否则和视频割裂。

### 5. 权威背书（数据型）
虚化背景 + 前景放真实的排名/星标/榜单卡片。
**适用**：确有真实成绩时。**没有就绝对不要编**。

### 6. 三态对比条
一张封面切三段，每段一个小图配一个关键词。
**适用**：技术向受众、愿意细看。手机上每格偏小，抓眼力弱于前几种。

### 7. 极简高级（留白型）
大留白 + 细霓虹线 + 发光字，Keynote 质感。
**适用**：需要安静、清楚的观感，或用户已认可这类方向；仍需在缩略图上读懂内容。

## 四、表达抽象特质的视觉符号

仅在视频内容需要强调动态或交互时考虑这些符号。真人经验分享无需添加此类元素；不要为凑图形增加噱头。

| 要传达 | 可选符号 |
|---|---|
| 会动 | 发光流动光带 + 拖尾 + 方向箭头 |
| 可交互 | 鼠标指针 + 节点高亮描边 + tooltip 弹出卡片 |
| 清晰 | 留白 40% 以上 + 只保留 4~6 个元素 + 背景压暗做景深 |

选能对应真实内容的符号即可，先保证观众读懂主题，不要求三种效果一起出现。

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 直接用视频原始截图当封面 | 双栏 IDE 缩略到手机上字全糊 | 放大裁切，只留 4~6 个元素 |
| 标题过长或过于省略 | 缩略图难读，或读不懂场景 | 缩短并分行，同时保留必要的主题词 |
| 整张架构图/界面塞进去 | 缩小后是一团马赛克 | 局部特写 |
| 纯 AI 文生图当封面 | 和视频内容割裂，观众有落差 | 真实截图做图生图输入 |
| 文字与底图缺少对比 | 缩略图难辨认 | 调整文字、底色或局部衬底，不固定要求深色 |
| 编造不存在的荣誉数据 | 用户返工，观众信任受损 | 拿不准就问用户 |
