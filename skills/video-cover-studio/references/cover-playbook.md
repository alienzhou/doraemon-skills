# Cover Playbook

从真实平台信息流里提炼的排版规律与创意方向。

---

## 一、B 站科技区封面的七条铁律

基于对真实首页信息流的观察总结：

**1. 文字是主体，不是配角**
文字占封面 30%~45% 面积。「AI变现没苦硬吃」「韩剧又封神了」「东北话真能消解沉重？」——字大到隔着一米能读。几乎没有"图为主、字为辅"的成功案例。

**2. 描边 + 阴影是标配**
黄字黑边、白字黑边、红底白字。在白色信息流背景下靠**高对比色块 + 粗描边**跳出来。细体、无描边、低对比的字会被直接吃掉。

**3. 双行结构占绝对多数**
第一行钩子（「过于强大」「逆向分析！」），第二行落点（「才有争议！」「背后的代价！」）。字号一大一小制造节奏。

**4. 黄 / 红 / 白三色打天下**
黄字出现频率最高。科技区尤其偏爱**深色底 + 亮黄或亮蓝字**。浅色底图在白色信息流里会被淹没，慎用。

**5. 人脸有效但非必需**
科技/开源区大量纯素材封面（课程、工具、教程）照样跑量。不出镜可以靠"界面截图 + 大字"的组合，或用 Q 版 IP 形象补上人脸红利。

**6. 疑问句和数字是高频钩子**
「到底有多强？」「真能消解沉重？」「怎么选？」「48h」「2026」「#571」。

**7. 克制风格属于内容本身有势能的账号**
纯艺术封面（风景、国创）能跑大流量，靠的是内容势能不是封面。**工具向/开源向视频属于"需要封面解释清楚我是什么"的品类**，老实走大字 + 界面证据路线。

## 二、平台规格与安全区

| 平台 | 尺寸 | 比例 | 安全区约束 |
|---|---|---|---|
| B 站 | 1920×1080（最低 1146×717） | 16:9 | 右下角有时长标签，左下角有播放量。**底部 12% 避免放关键信息** |
| 抖音 | 1080×1920 | 9:16 | **底部 25% 被文案/昵称/进度条遮挡；右侧 15% 被点赞评论栏遮挡**。关键信息放上部 60%、左侧 85% |
| 小红书 | 1080×1440 | 3:4 | 封面即笔记首图。**底部 15% 会被标题文字压住**。3:4 在瀑布流里占位最大，优先用这个比例而非 1:1 |

> 小红书特殊性：用户是"逛"而非"搜"，封面更看重**氛围感和信息密度平衡**。纯深色科技风在小红书偏冷，可适当加高饱和色块或留白，标题可以比 B 站更长（允许 12~16 字）。

## 三、七种验证过的创意方向

### 1. 左右对撞（因果型）
左半模糊的"输入"（代码、素材、原始状态），右半清晰高饱和的"输出"，中间巨大箭头。
**适用**：观众好奇"这东西怎么来的"。一眼说清输入→输出，不看标题也懂。

### 2. 悬念否定（反差型）
全屏放成品，压一行大字否定常识：「这张图，我没画」。
**适用**：中文社区，反差感强，评论区会自己吵起来。

### 3. 手稿对比（痛点型）
左边凌乱手绘/打红叉的旧方式，右边精美的新方式。
**适用**：情绪冲击最强，直戳目标人群的真实痛点。

### 4. 全息动态（技术炫技型）
3D 等距全息图 + 光带流动 + 鼠标悬停 tooltip。
**适用**：要表达"可交互、会动"。**必须配真实截图做底**，否则和视频割裂。

### 5. 权威背书（数据型）
虚化背景 + 前景放真实的排名/星标/榜单卡片。
**适用**：确有真实成绩时。**没有就绝对不要编**。

### 6. 三态对比条
一张封面切三段，每段一个小图配一个关键词。
**适用**：技术向受众、愿意细看。手机上每格偏小，抓眼力弱于前几种。

### 7. 极简高级（留白型）
大留白 + 细霓虹线 + 发光字，Keynote 质感。
**适用**：在满屏花哨封面里反而突出，但信息流抓眼力最弱，适合已有粉丝基础的账号。

## 四、表达抽象特质的视觉符号

静态封面要传达动态/交互特质，需要**可读的视觉符号**，缺一不可：

| 要传达 | 必需符号 |
|---|---|
| 会动 | 发光流动光带 + 拖尾 + 方向箭头 |
| 可交互 | 鼠标指针 + 节点高亮描边 + tooltip 弹出卡片 |
| 清晰 | 留白 40% 以上 + 只保留 4~6 个元素 + 背景压暗做景深 |

只放光带会被当成普通动效图，只放指针会被当成截图。**三者组合才成立**。

## 五、常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 直接用视频原始截图当封面 | 双栏 IDE 缩略到手机上字全糊 | 放大裁切，只留 4~6 个元素 |
| 主标题超过 8 字 | 手机上看不清 | 8 字以内，拆成双行 |
| 整张架构图/界面塞进去 | 缩小后是一团马赛克 | 局部特写 |
| 纯 AI 文生图当封面 | 和视频内容割裂，观众有落差 | 真实截图做图生图输入 |
| 用浅色底图 | 在白色信息流里被淹没 | 换深色主题或压暗 |
| 编造不存在的荣誉数据 | 用户返工，观众信任受损 | 拿不准就问用户 |
