# Video Cover Studio

为视频产出真实、清晰、让目标观众看出价值的多平台封面。

封面应让观众迅速读懂“这是给谁看的、与我有什么关系、点进去能得到什么”。吸引力来自明确的内容承诺，承诺要能在视频中兑现；没有点击率数据时，不宣称风格已被验证能提升点击率。

## 本用户的真人封面默认偏好

这是用户明确要求后续沿用的个人偏好，当前指令可以覆盖：

- 当前视频有用户本人可用画面时，默认用**当前视频中的真人形象＋轻度端正、亲和调整**制作封面，不让用户每次重新说明是否用真人、是否轻修。
- 从当前视频的全分辨率原帧选人像，保留原帧作身份参考。轻修以头部与视线更自然端正、眉眼放松、轻微笑意、光线和肤色更均匀为目标；本人辨识度优先，保留脸型、五官比例、年龄感与皮肤纹理。
- 同一条视频优先复用已选定的轻修人像。不同封面比例沿用同一形象和表情；只改标题、排版或比例时，不再次逐张美化、生成不同的脸。
- 新视频重新从该视频取材，延续修饰尺度；不要固定套用旧视频的人像、帽子、眼镜或服装。用户指定 IP、真实截图、不出镜、不修饰或先讨论时，按当前要求处理。

制作或调整真人时读 [references/real-person-retouch.md](references/real-person-retouch.md)，包含修饰边界、参考图使用和可复用提示词。

## 工作流总览

```
Step 1 视频解析 → Step 2 选帧 → Step 3 对齐观众与文案 → Step 4 主版与比例扩展 → Step 5 人物检查 → Step 6 归档
```

用户若只要其中一步（如"只换个文案"、"只加头像"），直接跳到对应步骤。

---

## Step 1：视频解析

拿到视频后先摸清底细，不要凭想象设计。

```bash
uv run <skill_directory>/scripts/probe_video.py --video <视频路径>
```

返回时长、分辨率、帧率。**时长决定抽帧密度**：3 分钟内每 6 秒一帧，更长则每 10~15 秒一帧。

---

## Step 2：抽帧与选帧

```bash
uv run <skill_directory>/scripts/extract_frames.py --video <路径> --interval 6 --outdir /tmp/vc_frames
```

抽完后用 Read 工具**逐张看**，不要只看文件名。选帧标准按优先级：

| 优先级 | 标准 | 原因 |
|---|---|---|
| 1 | 能代表视频核心内容，人物表情自然、眼睛清楚 | 先确保内容与身份可信 |
| 2 | 主体少而清楚，方便为标题留空间 | 支持手机缩略图阅读 |
| 3 | 真人出镜时，帽子、眼镜和完整面部便于保留 | 避免眨眼、模糊动作和不完整裁切 |
| 4 | 产品演示有真实功能或交互证据 | 只有主题确需说明功能时才选这类元素 |
| 5 | 与已认可的配色和整体观感协调 | 深底、亮色是可选手段，不是固定模板 |

黑帧（转场）必然抽到，直接排除。若 6 秒间隔错过了关键画面，用 `--timestamps` 精确补抽。

命中候选后**抽全分辨率原图**再用于合成，不要用压缩预览图。

---

## Step 3：确定创意方向

读 `references/cover-playbook.md`，里面有排版经验、七种可选创意方向，以及各平台安全区的参考。

先从原片和会话推断：视频面向谁？观众正在遇到什么问题、希望得到什么结果？把场景与观众利益说清楚，再考虑悬念或视觉风格。已有清楚上下文时继续制作，不重复询问。

经验分享、教程和求职建议类封面，优先用观众自己的话表达收益；“评价、主动性、实践深度”等内容术语可留在说明里。也不要为短句丢掉必要场景：例如只写“AI 写代码，你怎么加分？”可能不如“AI Coding 面试怎么拿高分？”清楚。

这类文案的推导方法和本用户认可案例见 [references/audience-first-covers.md](references/audience-first-covers.md)。它是判断参考，不是固定标题或统一配色。

---

## Step 4：生成封面

### 多比例交付

- 用户未限定比例、要跨平台封面时，默认交付 **16:9（1920×1080）、4:3（1920×1440）、1:1（1600×1600）、3:4（1080×1440）、9:16（1080×1920）** 五版。用户明确只要某几种时按其范围交付。
- 比例由**实际发布入口**决定，不把平台名绑定成唯一比例。先看上传页比例选项和预览；只能凭截图估计时说明「看起来是」，不能当作平台官方规格。
- 先确定一版主视觉，再围绕同一标题、系列编号和选定人物，按每种比例**重新排版**。不拉伸人脸、不把宽图居中硬裁成其他比例。
- 在文案或风格仍有分歧时，集中修改一张主版；用户认可方向后再扩展比例。已有认可和全套授权时直接完成，不为相同事项重复索要确认。
- 补边仅作临时兼容方案，文件名和交付说明明确标注「补边适配」，说明会增加留白；不能当成重新设计完成版。
- 完成后检查实际像素比例、整图及手机缩略图，确认标题首尾、系列号、人脸、IP 未被裁切或遮挡。交付一张带比例标签的总览，并标明各文件的建议入口；未经平台预览验证，不承诺上传后绝对不裁切。
- 详细布局、安全区与验收见 `references/cover-playbook.md` 第二节。`compose_cover.py` 当前仅有三种平台预设，不能声称已支持五版一键生成；4:3、1:1 需按本节另行排版生成并验尺寸。

两条路线，按需选择或都出：

**路线 A — 真实截图版（可信度高）**
用 `scripts/compose_cover.py` 把选中的真帧 + 文字排版合成。适合怕被说"图文不符"的场景。

**路线 B — 图像生成或编辑版**
按可用图像工具的要求使用真实参考。真人版应保留身份、自然神态、眼镜、帽子和服装特征，背景与排字服务内容。辉光、霓虹、夸张表情和 3D 装饰并非默认项；以用户认可的观感为准。

> 关键经验：**纯文生图会和视频内容割裂**。务必把真实截图作为参考图输入，在 prompt 里明确 `keep the genuine nodes recognizable, do not invent fake content`。

各平台尺寸与安全区见 `references/cover-playbook.md`。

## Step 5：人物与素材选择

对本用户，先按上文的真人默认偏好选材。没有本人可用画面时，结合内容选择真实截图或用户指定的 IP；不要因为技能里有现成立绘就自动使用 IP，也不要凭空生成一个真人替代讲述者。

真人合成后检查自然面部、完整帽子和眼镜、标题遮挡，以及实际画布里的完整面部是否进入平台预留区；只写了安全区参数不算完成检查。图像生成后的真人合成不能宣称与原帧像素逐点相同。

`assets/ip/` 保存可选的个人 Memoji IP（浅灰蓝熊耳针织帽 + 细黑框眼镜）、绿幕立绘与档案。采用该 IP 时可直接使用；扩展表情前先读 `assets/ip/ip-profile.json`，按 `references/ip-system.md` 对齐 appearance。

```bash
uv run <skill_directory>/scripts/compose_ip.py \
  --cover <封面路径> --ip <IP立绘路径> \
  --position bottom-left --scale 0.47
```

脚本自动做绿幕抠图、去绿溢出、边缘羽化、柔光底衬。

**采用 IP 时的放置参考**：
- 贴角落，占画面高度 40%~55%
- **必须避开已有文字和徽章**——合成后用 Read 检查，挡住了就缩小或换位
- 底部可轻微出血，显得自然

IP 形象的建立与扩展见 `references/ip-system.md`。

## Step 6：归档

封面存到**视频同目录**下的 `covers/` 子目录，命名带版本、比例和尺寸（平台仅作建议入口）：

```
covers/
├── 封面_v1_16比9_1920x1080.png
├── 封面_v1_4比3_1920x1440.png
├── 封面_v1_1比1_1600x1600.png
├── 封面_v1_3比4_1080x1440.png
├── 封面_v1_9比16_1080x1920.png
├── 封面_v1_比例总览.jpg
└── 发布文案.md
```

3:4 是竖版，不称为方版；只有 1:1 才是方版。修改另存版本，未获授权不覆盖或删除旧图。

`发布文案.md` 里放标题候选、各平台简介、话题标签。写法见 `references/copywriting.md`。

用户要求将完整制作资料归回原素材目录时，把成片、封面、发布文案和继续编辑所需的工程/缓存一起整理，保留旧版，修复相对路径并实际运行一次预览或读取检查。不要把“移动文件”视为覆盖原素材或发布社媒的授权。

## 诚实性红线

这条比任何视觉技巧都重要：

- **封面里的数据、荣誉、排名必须真实存在**。最容易翻车的就是顺手加一句"XX 榜第一""百万播放"这类没有出处的成绩——AI 极易自动补全出不存在的荣誉。凡是拿不准的战绩，**一律先问用户**。
- **界面元素要来自视频真实画面**，不要让 AI 凭空编造功能。
- 悬念可以有，欺骗不行。「这图我没画」是悬念；「三天涨粉十万」是欺骗。
