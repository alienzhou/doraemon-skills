# Video Cover Studio

为视频产出**真实、清晰、高点击率**的多平台封面。

核心信念：封面不是美术作业，是**信息流里的竞价广告位**。它只有 0.3 秒说服观众，且必须诚实——封面承诺的内容视频里要真的有。

---

## 工作流总览

```
Step 1 视频解析 → Step 2 选帧 → Step 3 定方向 → Step 4 生成 → Step 5 挂 IP → Step 6 归档
```

用户若只要其中一步（如"只换个文案"、"只加头像"），直接跳到对应步骤。

---

## Step 1：视频解析

拿到视频后先摸清底细，不要凭想象设计。

```bash
uv run <skill_directory>/scripts/probe_video.py --video <视频路径>
```

返回时长、分辨率、帧率。**时长决定抽帧密度**：3 分钟内每 6 秒一帧，更长则每 10~15 秒一帧。

---

## Step 2：抽帧与选帧

```bash
uv run <skill_directory>/scripts/extract_frames.py --video <路径> --interval 6 --outdir /tmp/vc_frames
```

抽完后用 Read 工具**逐张看**，不要只看文件名。选帧标准按优先级：

| 优先级 | 标准 | 原因 |
|---|---|---|
| 1 | 画面有**深色底 + 高饱和主体** | 信息流多为白底，深色封面更跳 |
| 2 | 主体元素**少而大** | 缩略图只有拇指大，元素多必糊 |
| 3 | 有**动态证据**（光带、箭头、进度） | 让静态封面传达"会动" |
| 4 | 有**交互证据**（鼠标、tooltip、高亮态） | 让封面传达"可操作" |
| 5 | 能代表视频**最有价值的 3 秒** | 诚实，避免标题党落差 |

黑帧（转场）必然抽到，直接排除。若 6 秒间隔错过了关键画面，用 `--timestamps` 精确补抽。

命中候选后**抽全分辨率原图**再用于合成，不要用压缩预览图。

---

## Step 3：确定创意方向

读 `references/cover-playbook.md`，里面有从真实平台信息流里提炼的排版规律、七种验证过的创意方向、以及各平台安全区。

**定方向前必须先问清或推断**：视频面向谁？观众最好奇什么？

经验：观众好奇的常常不是**成品本身**，而是**成品怎么来的**。一旦识别出这一点，封面的核心就该从"展示结果"切换到"展示因果"。找到这个「好奇点」，比挑风格重要得多。

---

## Step 4：生成封面

两条路线，按需选择或都出：

**路线 A — 真实截图版（可信度高）**
用 `scripts/compose_cover.py` 把选中的真帧 + 文字排版合成。适合怕被说"图文不符"的场景。

**路线 B — AI 增强版（冲击力高，推荐）**
用你手上任意 AI 生图能力的**图生图**模式，把真实截图当输入，叠加霓虹辉光等风格处理。这样既有视觉冲击，画面里的元素又是视频里真实存在的。

> 关键经验：**纯文生图会和视频内容割裂**。务必把真实截图作为参考图输入，在 prompt 里明确 `keep the genuine nodes recognizable, do not invent fake content`。

各平台尺寸与安全区见 `references/cover-playbook.md`。

---

## Step 5：挂载 IP 形象

有脸的封面更容易被注意到，但很多创作者不愿出镜。Q 版 IP 形象兼顾两者，还能沉淀成账号辨识度。

`assets/ip/` 下附了一套**示例形象**（含绿幕立绘与形象档案），可直接拿来跑通流程；正式使用时按 `references/ip-system.md` 生成属于你自己的形象替换即可。

```bash
uv run <skill_directory>/scripts/compose_ip.py \
  --cover <封面路径> --ip <IP立绘路径> \
  --position bottom-left --scale 0.47
```

脚本自动做绿幕抠图、去绿溢出、边缘羽化、柔光底衬。

**放置原则**：
- 贴角落，占画面高度 40%~55%
- **必须避开已有文字和徽章**——合成后用 Read 检查，挡住了就缩小或换位
- 底部可轻微出血，显得自然

IP 形象的建立与扩展见 `references/ip-system.md`。

---

## Step 6：归档

封面存到**视频同目录**下的 `covers/` 子目录，命名带平台和规格：

```
covers/
├── 封面_B站_横版_1920x1080.png
├── 封面_抖音_竖版_1080x1920.png
├── 封面_小红书_方版_1080x1440.png
├── 备选_*.jpg
└── 发布文案.md
```

`发布文案.md` 里放标题候选、各平台简介、话题标签。写法见 `references/copywriting.md`。

---

## 诚实性红线

这条比任何视觉技巧都重要：

- **封面里的数据、荣誉、排名必须真实存在**。最容易翻车的就是顺手加一句"XX 榜第一""百万播放"这类没有出处的成绩——AI 极易自动补全出不存在的荣誉。凡是拿不准的战绩，**一律先问用户**。
- **界面元素要来自视频真实画面**，不要让 AI 凭空编造功能。
- 悬念可以有，欺骗不行。「这图我没画」是悬念；「三天涨粉十万」是欺骗。
