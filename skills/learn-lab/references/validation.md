# 验收

分两部分：脚本验证**结构性属性**，人工验证**讲清楚了没有**。两部分都不能跳。

## 脚本能查什么、不能查什么

**能查**（教学设计的结构性属性）：

- 摘要行有没有给结论（存在性 + 长度 + 是否占位语）
- 标题是不是问句
- 展开后正文有没有分段
- 默认展开是否过多
- 每个读数有没有参照值
- 每个参数有没有动态提示和说明入口
- **实际拖动滑块**，验证读数、提示、结论三者是否真的改写
- 术语引用是否全部有定义
- 术语浮层是否出界
- 有没有答疑入口和提问模板导出
- 有没有数据来源标注
- 导航锚点是否可达
- 桌面 / 390px 窄屏是否横向溢出

**不能查**：

- 这个教具到底讲清楚了没有
- 类比是否恰当
- 结论是否正确
- 视觉是否可读

## 流程

### 0. 先过语法检查（改了页面脚本就必须做）

一个括号不配对会让整个 `<script>` 块静默失效：页面照常渲染，交互全死，
截图完全看不出来。所以先用 node 验一遍，再谈浏览器：

```sh
python3 -c "import re;s=open('index.html',encoding='utf-8').read();open('/tmp/_c.js','w').write(re.findall(r'<script>(.*?)</script>',s,re.S)[0])"
node --check /tmp/_c.js
```

### 1. 起服务

**这一步是浏览器工具的变通，不是课件的使用方式。** 工具通常拒绝 `file://`，
所以验收期间走 http；**课件本身必须 `file://` 双击可用**，
这个服务不能出现在交付说明里，验收完就停掉（见「清理」）。

```sh
python3 "<skill-dir>/scripts/serve.py" "/absolute/path/output-dir"
```

### 2. 跑脚本

```sh
myflicker-browser new_tab --url "http://127.0.0.1:<port>/index.html"
myflicker-browser console_messages --tab-id <tabId> --limit 40
myflicker-browser evaluate --tab-id <tabId> \
  --expression-file "<skill-dir>/scripts/pedagogy-check.js" --timeout-ms 60000
```

返回 `fail` / `warn` / `note` / `pass` 四档：

- **fail** —— 必须修
- **warn** —— 多数情况该修，除非主题本身不适用
- **note** —— 提示性，自行判断

### 3. 人工看截图

**这一步不能省。** 至少看四处：

1. **首屏** —— 标题是否说清这页回答什么、基准参数是否可见、有没有「怎么读这页」
2. **每个教具的默认态** —— 图例齐全吗、读数看得懂吗、结论在不在
3. **一个折叠块的收起态** —— 三要素（标题/摘要/标签）是否都能看到且不错位
4. **答疑面板展开态** —— 分类名像不像读者心理状态、列表排版是否正常

真实案例：三轮迭代里发现的所有视觉 bug 都是截图看出来的，脚本一个没抓到。

### 4. 关键状态回归

改了逻辑之后，手动测**状态翻转的那一刻**——这是课件要讲的核心，也最容易写错。

```js
// 切到越过临界点的预设，确认结论卡状态名、配色、正文全部切换
q('[data-preset="cloud"]').click();
```

### 5. `file://` 终验（用户的真实路径）

http 下正常不代表 `file://` 下正常 —— 受限 API（`localStorage`、
`fetch` 本地文件）只在这里暴露。所以最后必须按用户的方式打开一遍：

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --virtual-time-budget=5000 \
  --dump-dom "file:///absolute/path/index.html" \
  | grep -o 'data-target=' | wc -l   # 目录链接数，0 说明脚本没跑起来
```

注意用 `grep -o | wc -l`（数出现次数），不是 `grep -c`（数匹配行数）——
目录是 JS 动态生成的，整段 DOM 常被 dump 成一行，`-c` 会得到 1 或 2 这种误导值。

确认：页面渲染、页内目录生成、教具可操作、无控制台报错。
通过之后**停掉验收服务**（见「清理」），交付说明里不要出现它。

## 人工检查清单

脚本查不到的，逐项人看：

### 教学设计

- [ ] 把所有正文隐藏掉，教具还能操作吗（标签、图例、单位）
- [ ] 每个折叠：只读摘要能答出标题的问题吗
- [ ] 每个教具：拖动后我知道「所以呢」吗
- [ ] 答疑分类名像读者心理状态，不像教材目录
- [ ] 答疑问题用读者原话（源于真实对话的直接用当时问法）- [ ] 至少有一条「我该怎么做」类问题
- [ ] 模块之间有因果链，不是互相孤立

### 数据

- [ ] 每个数字归入三级可信度之一
- [ ] 推导值写出了算式
- [ ] 量级近似标了 `~`
- [ ] 说明了用的是哪个口径（dense/sparse、理论/实测）
- [ ] 简化模型声明了边界
- [ ] 派生值全部实时计算，无硬编码结论
- [ ] **单位和量纲逐个核对**（真实踩过：把带宽标成了延迟）

### 文字

- [ ] 结论先行
- [ ] 类比在量纲上成立
- [ ] 早先说错的地方有「勘误」块
- [ ] 无 AI 套话、成串排比
- [ ] 中文用中文标点，代码单位保留原文

### 视觉

- [ ] 数值用等宽字体（否则拖滑块时宽度跳变）
- [ ] 窄屏可读，无文本裁切
- [ ] 固定元素不遮挡页尾
- [ ] 颜色编码全页一致（同一语义同一颜色）

### 交付形态

- [ ] `file://` 双击打开，功能完整（不需要起任何服务）
- [ ] 有页内目录：常驻入口、能筛选、点一条即跳转并展开
- [ ] 零外部资源引用（`grep -o 'src="http\|href="http\|@import' index.html | wc -l` 为 0）
- [ ] 用到剪贴板等受限 API 的地方有降级兜底
- [ ] 回复里给的是「打开文件 + 点目录」，**不是** `#hash` 深链
- [ ] 验收用的本地服务已停掉

## README 的验证记录

**写实际修掉了什么，不要写「一切正常」。**

```markdown
### 过程中实际修掉的问题

1. **补正元素和被丢弃的同词** —— 两者取自同一数据源，
   「纠正」这件事根本看不出来；加了错误值序列后对比才成立
2. **「L1/寄存器延迟」标签写错** —— 单位是带宽不是延迟
```

两个作用：让用户知道你真的测了；下次迭代时自己能避开同样的坑。

同时记录实测数值便于回归：

```markdown
- 模块 06：本地 2.59×「显著加速」/ 云端 batch=512 → 0.73×「反而更慢」
- 模块 08：四张卡拐点实测 164 / 76 / 153 / 296，与手算一致
```

## 清理

```sh
pkill -f "http.server <port>"
```

不要把临时脚本留在工作区。
